# Лабораторная работа 1: RISC-V Ассемблер

Вариант 6
Найти сумму элементов массива (N=4, M=4)

Описание
Программа вычисляет сумму всех элементов двумерного массива 4×4.

Массив
        {10,  22, 33,  4},
        {52,  64,  17,  8},
        {91,  10, 111, 3},
        {1, 14, 52, 31}

Ожидаемый результат: 523

Реализация

C код
Функция `sum_array(int N, int M, int arr[N][M])` использует два вложенных цикла для обхода массива.

Ассемблер RISC-V
ABI: Передача аргументов через регистры a0 (N), a1 (M), a2 (указатель на массив)
Возврат: Результат в регистре a0
Callee-saved: Регистры s0, s1, s2 сохраняются на стеке
Адресация: matrix[i][j] = base + (i*M + j)*4

Компиляция

riscv64-unknown-elf-gcc -march=rv32i -mabi=ilp32 main.c -o main.elf
riscv64-unknown-elf-objdump -D main.elf > main.dump
